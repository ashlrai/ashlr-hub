Measured, not estimated

One bug was costing 23,500 tokens a turn.

Claude Code appends a token counter to every request, and it changes each turn. Verse was folding that into the system prompt, ahead of the whole conversation, so the prompt prefix changed on every request and llama.cpp could reuse none of its cache. Every turn reprocessed the entire context. The work was correct the whole time. It was just slow.

How local actually works

Discovery and dispatch are different problems.

Most local setups collapse them and then wonder why the model picker goes empty. Verse keeps them apart, which is what lets you move dispatch onto the fast runtime without losing the seat list.

Discovery stays on Ollama

Which models you have, their context window, and whether they can call tools at all, come from Ollama. A model without tool support cannot drive an agent session, so Verse hides it rather than letting you pick something that will fail on the first turn.

Dispatch can move to llama.cpp

Turns go to a llama-server with continuous batching, through a proxy that normalises the request so the model's own chat template accepts it. That is the path the numbers above were measured on. It is opt-in, and an unset or malformed setting falls back to the lane that already works rather than to a dead port.

Autonomy

Out of the loop, not out of control.

Verse can run agents with nobody watching. That is only worth having if the blast radius is something you set deliberately, so the limits are part of the product rather than a setting you hope someone remembered.

Enrollment scope
An autonomous agent can only touch repositories you enrolled. Adding a folder to a project does not silently widen what the unattended lane can reach.
Proposals, not pushes
Unattended work lands as a proposal you approve. Anything that leaves the machine, a branch, a pull request, a message, waits for that click and tells you what it will do first.
Usage ceilings
Cap what the autonomous lane may spend, as a share of each subscription. Local seats cost nothing, so a fleet can keep working after the paid ceiling is reached.
Kill switch
One file on disk stops every autonomous effect immediately. It is checked on the effect itself, not on the scheduler, so a loop already in flight cannot outrun it.

Get started

Three steps to a working fleet.

Install and open the console

Verse runs as a local web console. It finds the CLIs you already have installed.

# install, then open the console
npm i -g @ashlr/hub
ashlr verse

Bring up the local runtime

Starts llama-server with batching slots and the request proxy in front of it.

ashlr local-runtime start --slots 4

Put local turns on the fast lane

Opt in, because the fallback should be the lane that already works.

export ASHLR_VERSE_LOCAL_DISPATCH=llama-server

What you need

A Mac with enough memory to hold the weights, around 48 GB resident for a 27B model at four-bit. Ollama for model discovery. Whichever agent CLIs you already use, signed in as you normally would. Verse never asks for your credentials; it drives each CLI with its own pinned profile so accounts stay separate.
