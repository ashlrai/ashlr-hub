# Integration findings

Prior increment established one real native Codex read-only calibration with
fresh pinned-account quota and an immutable 4-check evaluator. It did not connect
native resource workers to Universe generation. The installed newer CLI works;
the old global standalone CLI remains unchanged and incompatible with the model.

Current exploration follows existing generation, candidate parsing, campaign
budget/replay and public provenance contracts before choosing implementation.

## Implemented decisions

- Portable manifests pin pool ID, canonical policy/bindings digest and allowed
  workers. Execution-only runtime files hold paths, outside the Universe store.
- The existing resource runtime owns atomic admission, task caps, shared-account
  capacity, cooldowns and settlement; Universe does not create per-trial ledgers.
- Response-only native tasks use a separate empty private Git workspace. Native
  read-only is not a tool-free or broad filesystem-read isolation guarantee.
- Candidate JSON still passes the existing scoped edit broker, frozen-artifact
  evaluator and archive comparator. Resource completion is not acceptance.
- Stable task IDs bind Universe/run/variant identity. Changed full task envelopes
  conflict, exact replays have no recoverable output, and neither redispatches.
- Resource handoffs have separate coverage counters; actual native provider
  request count and unreported tokens remain unknown.
- Campaigns pause on operational resource failure but honor deadline/owner
  controls first. Existing reservations are not refunded.
- Current explicit refusals veto dispatch across account aliases even when
  durable observations are newer. Missing unused aliases do not fabricate denial.
- Portfolio runtime forwarding and automatic quota collection are not included.
  Explicit run/campaign execution works; separately commissioned collectors are
  required to keep observations fresh during unattended use.

## Actual acceptance scope

Prepare an isolated installed-package acceptance using the already available
qwen3-coder:30b local model, two generation handoffs, a fixed port-parser evaluator
and local-only delivery. This is a bounded engineering calibration, not a general
quality benchmark or production feature acceptance. No native account cap reset,
provider fallback, service activation, model download or registry publication.
