# Findings

- PR360 comparison source is merged, independently packaged and verified. It does
  not activate a resident fleet or publish npm.
- North Star prioritizes executable engineering outcomes and empirical harness
  improvement, not token expenditure alone or repeated readiness reports.
- The existing local gate can qualify releases without Actions; hosted publication
  provenance and stale policy bindings remain separate source gaps.

- The current model broker can only replace existing files; this concretely blocks
  new modules and deletions during autonomous candidate construction.
- Existing archive copy/hash/freeze and Git delivery already handle whole trees.
  The missing pieces are declared-file state, bounded operations and replay.
- Prior feedback assumes all mutable files exist. Missing files must be represented
  only in the opt-in mode without changing frozen legacy feedback bytes.
- The goal-loop Markdown parser scans fenced examples as live structure. A private
  exact-source challenge can exercise helper creation, caller updates, rejected
  feedback and source-line preservation without modifying the real parser this turn.
- Claude strategist has an inference-only CLI precedent, but it lacks Universe's
  cancellation/request accounting contract. Existing general engine flags are not
  safe drop-in transport isolation for this new feature.
- Exact local installation is a useful later capability; current resident adapters
  remain unavailable. Do not confuse a local CLI install with resident activation.
