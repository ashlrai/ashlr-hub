# P13 — cold verifier adapter
Scope: bounded in-memory verification; no process, provider, service or effect activation.
API: createColdVerificationRequest and verifyUniverseCold in src/core/universe/cold-verifier.ts.
Inputs: pinned spec digest, candidate diff and test log only; no implementer narrative fields.
Bindings: exact input digest, fresh invocation nonce and enrolled verifier execution identity.
Independence: distinct enrolled execution IDs only; not proof of distinct humans or models.
Limits: 256 KiB diff, 64 KiB log and 30-second maximum adapter wait.
Cancellation requests transport abort but does not attest process settlement or hard preemption.
Verification: 45 focused tests, scoped ESLint and full TypeScript check pass; parent runs release gates.
Trace: P13.trace.json is an explicit unsigned stub, not authenticated execution evidence.
