# P35 — deterministic payment broker simulation
Scope: pure request/reserve/settle/deny reducer; no payment rail, network or provider.
API: createPaymentBrokerState and reducePaymentBroker in src/core/universe/payment-broker.ts.
Policy: currency, merchant/scope allowlists and checked integer minor-unit request/day caps.
Identity: immutable request and reservation digests, retained IDs and state CAS digests.
Accounting: prior-day outstanding holds carry forward; downtime never banks daily allowance.
Settlement: failed/unknown stays held; no void/refund API; deny only affects unreserved requests.
Boundary: caller must authenticate settlement facts and serialize durable state; no transfer is proved.
Verification: 38 focused tests, scoped ESLint, full TypeScript check and diff checks pass; parent runs release gates.
Trace: P35.trace.json is an explicit unsigned stub, not authenticated payment evidence.
