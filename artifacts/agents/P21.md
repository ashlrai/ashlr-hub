# P21 — Private harness hypothesis archive
Status: implemented locally; unsigned evidence; parent integration pending.
API: registerHarnessArchive, storeHarnessCandidate, readHarnessArchive; every call has an explicit root.
Registration freezes baseline bytes, evaluator bytes/digest and an exact mutable-file allowlist.
Candidate records retain full content, digests, hypothesis, reason and supplied outcome, including failures.
Governance, safety checks, evaluator fixtures, merge.ts and evaluator paths cannot be mutated through this archive.
Effective requires candidate/evaluator/verifier receipt linkage; independentlyVerified remains false.
Storage serializes exact byte/count admission under an archive owner lock; missing/corrupt archives never autoheal.
Bounds: 256 files and 256 KiB per candidate, combined 256 KiB registration snapshots, 256 candidates, 64 MiB store reads.
Verification: 38 focused tests, typecheck, scoped ESLint and diff checks pass; no candidate execution, promotion or Git effects.
