# Phantom architecture

The maintained runtime overview is [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Use [the package manifest](package.json) for the runtime dependency inventory and
[the companion guide](docs/COMPANIONS.md) for the supported integration boundaries.
Runtime authority and installation still require their own qualification; an
architecture diagram does not establish that an account or resident is ready.

The original CLI/index/Raycast design is retained in
[the 3.29.5 source history](https://github.com/ashlrai/phantom/blob/f04d57e31e56ddba4230ffb49111abe615cd2f19/ARCHITECTURE.md).
It describes the early `ashlr-hub` design and is not the current dependency or
runtime contract.
