# Ashlrverse field guide

Static documentation index, not a worker API or execution authorization.

The source experiment path requires Git, Node.js 24+ and macOS sandbox-exec. Hosted documentation and recorded evidence do not require a worker account.

## Compatibility

Package: `@ashlr/hub`. CLI: `ashlr universe`. SDK: `@ashlr/hub/universe`.

## Discover your selected binary

```sh
node bin/ashlr docs --agent --json
```

Run from the trusted, built checkout you intend to use. Read each command's help. Discovery describes effects; it does not grant authority or prove worker readiness.

## Run your first experiment

Reproduce a two-generation search with fixed workers. No model account is needed; the demo creates local files and executes sandboxed code.

Effect: Local execution.

[Reproduce the demo](https://github.com/ashlrai/ashlr-hub/blob/master/docs/DEMO.md)

## Inspect before dispatch

Read campaign state, resource configuration and delivery receipts before choosing the next action. Healthy records are not proof of authenticated workers.

Effect: Read-only discovery.

[Open the agent command guide](https://github.com/ashlrai/ashlr-hub/blob/master/docs/README.md#for-coding-agents)

## Allocate worker capacity

Commission supported native accounts or local models, preserve your personal reserve, and verify an explicit resource configuration.

Effect: Operator configuration.

[Configure resources](https://github.com/ashlrai/ashlr-hub/blob/master/docs/RESOURCE-POOLS.md#commission-native-accounts-and-local-capacity)

## Run bounded campaigns

Turn an objective into competing variants with fixed evaluation, resource limits and recorded outcomes. Continue improving inside the delegated budget.

Effect: Explicit execution.

[Set up a campaign](https://github.com/ashlrai/ashlr-hub/blob/master/docs/ASHLR-UNIVERSE.md#continue-autonomously-with-a-bounded-campaign)

## Deliver and reconcile

Use an explicit delivery plan for local branches. Reconcile completed campaign receipts without rerunning workers; a branch is not a production release.

Effect: Local branch handoff.

[Follow the delivery contract](https://github.com/ashlrai/ashlr-hub/blob/master/docs/ASHLR-UNIVERSE.md#deliver-supervised-campaign-results)

## Improve the system

Understand the local kernel and independent ecosystem projects. Use useful accepted changes per token and hour as the target—not activity alone.

Effect: Architecture and contribution.

[Read the North Star](https://github.com/ashlrai/ashlr-hub/blob/master/docs/NORTH-STAR.md)

## Interpret evidence

- Inspect structured outcomes, not exit code alone. A healthy check can still describe a held or completed campaign.
- Valid resource configuration is not an authenticated connection or proof of remaining provider quota.
- Keep campaign completion, evaluated usefulness, local delivery and production acceptance distinct.
- Keep roots, target branches, budgets and operator reserves explicit. Do not publish raw startup tokens or private runtime records.
