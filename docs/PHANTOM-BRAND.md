# Phantom by AshlrAI

Phantom is the engineering agent workbench, formerly Ashlr Verse. AshlrAI, Inc. is the company; [ashlr.ai](https://ashlr.ai) remains the company site.

This presentation release preserves `@ashlr/hub`, the `ashlr` command, `ashlr verse`, the `ashlr-hub` repository, `/verse/` and `/verse/m/` routes, existing saved data and signed authority. The existing `phantom` command belongs to Phantom Secrets and is not replaced by the workbench.

The native window, menus and About identify Phantom. The current compatible installation is still `Ashlr.app`; renaming it to `Phantom.app` requires the separately verified installer and updater migration. The bundle identifier, signing identity, custody keys and launch-agent names are retained.

The current README and landing-page screenshots come from a compiled Phantom build using explicitly labeled sample accounts. They demonstrate the interface and do not establish provider execution or resident autonomy. Existing screenshot filenames, package names and URL paths retain their identities.

## Provider and tool identity marks

The landing illustration identifies resources, not endorsements or active accounts. Claude, OpenAI, Grok and Ollama geometry is reused from the existing `ProviderLogo.tsx` Lobe Icons paths with the MIT notice alongside the new SVG assets. Devin retains the exact first-party vendor favicon already stored in `site/assets/devin-mark.svg`.

Vercel's triangle comes from its official [brand assets](https://vercel.com/geist/brands); Supabase's unchanged green icon comes from its official [brand kit](https://supabase.com/brand-assets.zip). These marks preserve vendor geometry and colors. Colored ghosts, routes and islands are Phantom's presentation, separate from the provider artwork. Vercel and Supabase appear as examples of configured tool connections; this scene does not provision either service.

The landing scene uses local SVGs, CSS and one small script, with no visualization framework or provider calls. Playback is optional, pauses offscreen or in the background, and motion is disabled when the viewer prefers reduced motion. Its resource selector describes connection types and cannot sign in, dispatch work or spend credits.

## Display precision

Usage, credit balances, cost estimates, token counts and performance metrics use two significant figures. Exact readings remain in source data and deliberate inspection metadata. Dates, versions, model names and binary capacity names, input limits, navigation positions, exact chart axes and incomplete-history lower bounds retain their meaning; rounding must not change a quota decision or suggest that a resource has reached an endpoint.
